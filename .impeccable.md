## Design Context

### Users
Corroya's OC Universe is for the creator and visitors browsing an original-character portfolio. Visitors are exploring characters, worlds, and image collections as if walking through a quiet digital exhibition.

### Brand Personality
Refined, restrained, editorial. The interface should feel like an art-book portfolio and museum wall, not a dashboard or admin panel.

### Aesthetic Direction
Use a warm neutral exhibition palette, precise typography, sparse navigation, and an expansive draggable image canvas inspired by magazine collage layouts. Avoid AI generation language, noisy effects, backend-admin patterns, and overly playful decoration.

### Design Principles
- Lead with atmosphere: the first screen should feel like a gallery space.
- Make images the primary surface, with text and navigation kept quiet.
- Preserve editorial restraint through spacing, subtle lines, and muted color.
- Keep mobile interaction touch-friendly without hiding core browsing.
- Use static mock data only in the first phase.
